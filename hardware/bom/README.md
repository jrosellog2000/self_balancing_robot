# Self-Balancing Robot

Self-balancing two-wheel robot built on an ESP32, MPU-6050 IMU, and TB6612FNG dual motor driver, using PID control to stay upright on 3–6V geared DC motors.

## Bill of Materials (ESP32 build)

| Component | Qty | Spec |
|---|---|---|
| Microcontroller | 1 | ESP32-S3-N16R8 (DevKitM-1-style board) |
| IMU | 1 | GY-521 breakout (MPU-6050) |
| Motor driver | 1 | TB6612FNG dual motor driver breakout |
| DC gear motors | 2 | 3–6V, no encoders |
| Perfboard/PCB | 1 | 5x7 cm |
